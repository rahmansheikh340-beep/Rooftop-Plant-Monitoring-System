# Automated Rooftop Plant Monitoring System

## 📋 Overview
IoT-enabled solution for automated plant care on rooftops
using real-time monitoring and intelligent irrigation control.

## ✨ Features
- Real-time soil moisture monitoring
- Automated irrigation control
- Remote access via mobile app
- Water conservation (40% savings)
- IoT-enabled WiFi connectivity

## 🔧 Hardware Components
- NodeMCU ESP8266 Microcontroller
- Soil Moisture Sensor
- pH Sensor
- Ultrasonic Sensors (2x)
- Relay Module
- DC Pump Motor
- SMPS 5V Power Supply
